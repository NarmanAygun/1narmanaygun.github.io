Информационная безопасность (Cyber Security)

1. Что такое триада CIA?

Триада CIA является фундаментальной моделью информационной безопасности и включает:

  • Confidentiality (Конфиденциальность) — защита данных от несанкционированного доступа.
  • Integrity (Целостность) — обеспечение точности и неизменности данных.
  • Availability (Доступность) — доступность информации для авторизованных пользователей.

2. Что такое SQL Injection?

SQL Injection — это атака, при которой злоумышленник внедряет SQL-команды через формы ввода для получения доступа к базе данных.

SELECT * FROM users WHERE username='' OR '1'='1';

Защита:

  • Параметризованные запросы
  • ORM
  • Валидация данных
  • Минимизация прав доступа

3. Что такое RBAC?

Role-Based Access Control — управление доступом на основе ролей.

Преимущества:

  • Простое управление правами
  • Соответствие принципу минимальных привилегий
  • Повышение безопасности
  • Упрощение аудита

5. Виды резервного копирования

  • Full Backup — полное резервное копирование.
  • Incremental Backup — сохраняются только изменения после последнего backup.
  • Differential Backup — изменения после последнего полного backup.

6. Audit Logs

Журналы аудита позволяют:

  • Отслеживать действия пользователей
  • Проводить расследования инцидентов
  • Контролировать доступ
  • Выполнять требования ISO 27001, PCI DSS и GDPR

7. MFA (Multi-Factor Authentication)

MFA требует несколько факторов аутентификации:

  • Пароль
  • Смартфон или токен
  • Биометрия

Даже если пароль украден, злоумышленник не сможет войти без второго фактора.

8. Immutable Backup

Immutable Backup — резервная копия, которую нельзя удалить или изменить до истечения установленного срока хранения.

Защищает от:

  • Ransomware
  • Инсайдерских угроз
  • Случайного удаления данных

9. Data Masking и Tokenization

Data Masking

4111-****-****-1234

Часть данных скрывается.

Tokenization

4111111111111234 → TKX985462

Оригинальное значение заменяется токеном.

10. Как защитить базу данных?

  • Шифрование данных
  • Использование MFA
  • RBAC
  • Регулярные обновления
  • Резервное копирование
  • Мониторинг активности
  • Firewall
  • IDS/IPS системы

11. Угроза, уязвимость и риск

Угроза — потенциальная опасность.

Уязвимость — слабое место системы.

Риск — вероятность реализации угрозы через уязвимость.

Риск = Угроза × Уязвимость

12. Причины утечек Yahoo и Equifax

Yahoo

  • Слабые механизмы защиты
  • Компрометация аккаунтов

Equifax

  • Неустановленные обновления безопасности
  • Уязвимость Apache Struts

13. Внутренние и внешние угрозы

Внутренние угрозы

  • Сотрудники
  • Подрядчики
  • Инсайдеры

Внешние угрозы

  • Хакеры
  • Киберпреступники
  • Конкуренты
  • APT-группы

14. Социальная инженерия

Манипулирование людьми для получения доступа к информации.

Примеры:

  • Phishing
  • Spear Phishing
  • Vishing
  • Smishing
  • Pretexting

15. Phishing и Spear Phishing

Phishing Spear Phishing
Массовая рассылка Целевая атака
Общие сообщения Персонализированные сообщения
Любые пользователи Конкретная жертва

16. DDoS-атака

DDoS нарушает принцип Availability (Доступность).

Атакующие перегружают сервер большим количеством запросов, делая сервис недоступным для легитимных пользователей.

17. Принцип минимальных привилегий

Пользователь получает только те права доступа, которые необходимы для выполнения его рабочих задач.

18. Матрица рисков

Используется для оценки вероятности возникновения угроз и степени ущерба.

Risk = Probability × Impact
Вероятность Воздействие Уровень риска
Высокая Высокое Критический
Средняя Среднее Средний
Низкая Низкое Низкий

  4. Предложить меры защиты.

Вывод:

Модель CIA является фундаментом информационной безопасности и применяется практически во всех современных информационных системах.
